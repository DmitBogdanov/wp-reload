# Участие в проекте

Спасибо за интерес к WP Reload.

WP Reload — информационный проект о WordPress, доработке WordPress, обновлении, поддержке и практическом продвижении сайтов.

## Что можно предложить

Мы приветствуем:

- сообщения об ошибках в материалах;
- исправления неточностей;
- предложения новых тем;
- улучшения инструкций;
- дополнения к примерам кода;
- предложения по улучшению структуры материалов.

## Перед созданием Issue

Проверь:

1. Нет ли уже аналогичной Issue или Discussion.
2. Относится ли вопрос непосредственно к материалам проекта.
3. Можно ли точно описать проблему или предложение.

## Для исправления ошибки

Укажите:

- страницу или файл;
- что именно обнаружено;
- как должно быть правильно;
- при необходимости — ссылку на документацию или другой надёжный источник.

## Pull Request

Для небольших исправлений:

1. Создайте fork репозитория.
2. Создайте отдельную ветку.
3. Внесите изменения.
4. Проверьте Markdown, код и структуру файлов.
5. Создайте Pull Request с кратким описанием изменений.

Все изменения должны проходить автоматические проверки CI.

## Стиль материалов

Материалы должны быть:

- практичными;
- понятными владельцам WordPress-сайтов без глубоких знаний веб-разработки;
- проверяемыми;
- без необоснованных обещаний;
- без искусственного наполнения ключевыми словами.

При описании технических решений предпочтение отдаётся конкретным инструкциям, командам, настройкам и проверяемым результатам.
