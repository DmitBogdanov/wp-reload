# WP Reload — information page

Экспертный информационный проект о **WordPress**, **доработке WordPress**, обновлении, поддержке и продвижении сайтов.

## Назначение

Репозиторий содержит структурированные материалы WP Reload для публикации информационной страницы на GitHub.

## Структура

- `docs/` — основной контент страницы и связанные материалы.
- `examples/` — языковые и структурные стабы.
- `assets/` — изображения, иконки и прочие статические ресурсы.
- `.github/` — GitHub workflows и шаблоны.

## Проект

WP Reload — экспертный блог для владельцев WordPress-сайтов, не обладающих глубокими познаниями в веб-разработке.

Основной сайт: https://wordpress.forcej.ru/
