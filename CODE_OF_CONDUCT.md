# Правила поведения

Мы стремимся поддерживать профессиональное и конструктивное сообщество вокруг WP Reload.

## Ожидаемое поведение

Участники должны:

- уважительно относиться к другим участникам;
- обсуждать проблему, а не личность;
- предоставлять точную и проверяемую информацию;
- конструктивно относиться к замечаниям;
- придерживаться тематики проекта.

## Недопустимое поведение

Не допускаются:

- оскорбления и личные нападки;
- дискриминационные высказывания;
- преследование участников;
- намеренная публикация вредоносного или опасного содержимого;
- спам;
- намеренное размещение заведомо ложной информации;
- публикация чужих персональных данных без разрешения.

## Технические обсуждения

Разногласия по реализации являются нормальной частью технической работы.

При спорных вопросах следует опираться на:

- документацию;
- воспроизводимые результаты;
- исходный код;
- логи;
- практические тесты.

## Модерация

Материалы и сообщения, нарушающие эти правила, могут быть отредактированы или удалены.

В зависимости от ситуации участнику может быть ограничена возможность участвовать в Issues, Discussions или Pull Requests.

## Контакты

Вопросы по нарушению правил можно направить сопровождающим проекта через GitHub Issues или Discussions.
