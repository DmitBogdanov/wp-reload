# WP Reload v1.0.0

Первый стабильный релиз информационной страницы WP Reload.

## Что добавлено

- Основная информационная страница проекта на PHP.
- Материалы о WordPress, доработке, обновлении, настройке, поддержке и продвижении сайтов.
- FAQ из 16 вопросов и ответов.
- JSON-LD: Article, FAQPage, HowTo и SoftwareSourceCode.
- Пошаговая инструкция по доработке сайта на WordPress.
- Блок «Читайте также» с 12 тематическими материалами.
- Примеры PHP, JavaScript, HTML5, CSS3, Python, ASP.NET, Docker, Nginx и Apache.
- Composer и npm-конфигурации.
- ESLint и CI-проверки GitHub Actions.
- Community-файлы.
- PDF-версия.
